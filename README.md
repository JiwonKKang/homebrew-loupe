# Loupe

Builds of Loupe — a human-first code review app for macOS (universal: Apple Silicon + Intel).
This repository is both the download location and the Homebrew tap.

## Install

```bash
brew tap jiwonkkang/loupe https://github.com/JiwonKKang/loupe-releases
brew install --cask loupe
```

## Update

```bash
brew upgrade --cask loupe
```

Already installed from the old `JiwonKKang/homebrew-loupe` tap? Point it here once:

```bash
brew tap --custom-remote jiwonkkang/loupe https://github.com/JiwonKKang/loupe-releases
```
